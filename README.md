# Sindhnama

A student's documentation of Sindh's identity — its forts, lakes, and people — told through real visits.

## Problem Statement

Sindh's tourism information online is scattered, outdated, or written by people with no real connection to the region. I built Sindhnama to fix that gap — a locally authored, firsthand guide to the places and people that genuinely represent Sindh's history, nature, and culture, for travelers who want more than a generic listicle.

## Features

- Multi-page site covering destinations across 3 categories: Historical & Cultural, Natural & Scenic, and Community & Culture
- Personal, firsthand descriptions for places I've actually visited (Umerkot Fort, Bhambhore Museum, Mohatta Palace, Makli Necropolis, Keenjhar Lake), alongside honestly researched entries for places and stories I haven't personally experienced firsthand (Thar Desert, the students of Thar)
- Fully responsive design, tested across desktop and mobile screen sizes
- Image galleries using semantic figure/figcaption markup with accessible alt text
- Custom typography with Google Fonts (Playfair Display for headings, Inter for body text)
- Hover effects on navigation links, category cards, and images for a more natural feel
- Card-based layouts for travel tips and community stats, a two-column layout on the About page
- A consistent, custom design system built entirely with CSS variables, no frameworks
- Clean, semantic HTML throughout, with proper heading hierarchy and accessible navigation

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, CSS custom properties, media queries, pseudo-classes)
- Google Fonts
