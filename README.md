# Sindhnama

A student's documentation of Sindh's identity — its forts, lakes, and museums — told through real visits.

## Problem Statement

Sindh's tourism information online is scattered, outdated, or written by people with no real connection to the region. I built Sindhnama to fix that gap — a locally authored, firsthand guide to the places that genuinely represent Sindh's history, nature, and culture, for travelers who want more than a generic listicle.

## Features

- Multi-page site covering 10 destinations across 3 categories: Historical & Cultural, Natural & Scenic, and Museums & Institutions
- Personal, firsthand descriptions for places I've actually visited (Umerkot Fort, Bhambhore Museum, Wazir Mansion, Keenjhar Lake, State Bank of Pakistan Museum, PAF Museum), alongside honestly researched entries for places I haven't personally visited yet (Mohatta Palace, Thar Desert)
- Fully responsive design, tested across desktop and mobile screen sizes
- Image galleries using semantic figure and figcaption markup with accessible alt text
- Custom typography with Google Fonts (Playfair Display for headings, Inter for body text)
- Hover effects on navigation links, category cards, and images for a more natural feel
- A consistent, custom design system built entirely with CSS variables, no frameworks
- Clean, semantic HTML throughout, with proper heading hierarchy and accessible navigation

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, CSS custom properties, media queries, pseudo-classes)
- Google Fonts
