# Sindhnama

**A student's documentation of Sindh's identity — its forts, lakes, and museums — told through real visits.**

## Problem Statement

Sindh's tourism information online is scattered, outdated, or written by people with no real connection to the region. Sindhnama is my attempt to fix that gap — a locally authored, firsthand guide to the places that genuinely represent Sindh's history, nature, and culture, built for travelers who want more than a generic listicle.

## Features

- Multi-page site covering 10 destinations across 3 categories: Historical & Cultural, Natural & Scenic, and Museums & Institutions
- Personal, firsthand descriptions for places I've actually visited (Umerkot Fort, Bhambhore Museum, Wazir Mansion, Keenjhar Lake, State Bank of Pakistan Museum, PAF Museum), alongside honestly researched entries for places I haven't personally visited yet (Mohatta Palace, Thar Desert)
- Fully responsive design — tested and working across desktop and mobile screen sizes
- Image galleries for each destination using semantic <figure>/<figcaption> markup with accessible alt text
- A consistent, custom design system (color palette, typography, spacing) built entirely with CSS variables — no frameworks
- Clean, semantic HTML throughout — proper heading hierarchy, landmarks, and accessible navigation

## Technologies Used

- HTML5 (semantic elements only — no unnecessary <div>s where semantic tags applied)
- CSS3 (Flexbox, Grid, CSS custom properties, media queries — no frameworks, no JavaScript)
